# GRACE — навигация для AI-агентов

Этот репозиторий содержит методологию **Graph-RAG Anchored Code Engineering (GRACE)**. Полное нормативное содержание находится в тематических документах docs/. Этот файл — точка входа и карта навигации для AI-агентов, а не замена методологии. Для последовательного чтения людьми используй [docs/README.md](docs/README.md): там описаны назначение документов и рекомендуемый порядок изучения.

## Как работать с документацией

1. Определи тему текущей задачи по автоматически формируемой карте документов и полному оглавлению ниже.
2. Прочитай указанные документы целиком, включая связанные разделы, на которые они ссылаются.
3. Не загружай все документы из docs/ без необходимости: сначала выбери релевантную область.
4. Если задача затрагивает несколько областей, прочитай документы всех затронутых областей.
5. Не выводи отсутствующие в GRACE правила из общих инженерных практик. Отделяй содержание методологии от собственных предложений.
6. При обнаружении противоречия или пробела укажи конкретные документы и формулировки; не разрешай его молча.

## Выбор документов по задаче

- Найди в карте и полном оглавлении все разделы, относящиеся к текущей задаче.
- Прочитай документы, на которые ведут соответствующие записи; учитывай связанные разделы и междокументные зависимости.
- Если задача затрагивает несколько областей, прочитай документы всех затронутых областей.
- Не используй номера документов: имена и состав файлов формируются автоматически из grace_source/GRACE.md.

## Источник истины и целостность

- Единственный источник содержания методологии — [grace_source/GRACE.md](grace_source/GRACE.md). Не удаляй, не перемещай и не заменяй его контрольной суммой или manifest.
- docs/ содержит тематические фрагменты, которые должны в точности воспроизводить исходник при конкатенации в установленном порядке.
- docs/README.md — самостоятельный навигационный документ для людей; он не является фрагментом исходника и не входит в manifest.
- docs/manifest.json содержит только производные метаданные. Он не является эталоном содержания и не может заменить исходный файл.
- Перед завершением изменений документации запускай `python3 scripts/check_grace_split.py verify`. Команда обязательно читает grace_source/GRACE.md; отсутствие исходника или любое побайтовое расхождение означает FAIL.
- Изменения методологии вносятся в grace_source/GRACE.md. Затем выполни `python3 scripts/check_grace_split.py split`, чтобы заново сформировать docs/ и manifest из источника, и повтори verify.
- Не редактируй тематические документы независимо от источника; docs/README.md является отдельным вручную поддерживаемым навигационным файлом.
- CI запускает ту же проверку при изменении grace_source/, docs/, AGENTS.md, README.md или валидатора.
