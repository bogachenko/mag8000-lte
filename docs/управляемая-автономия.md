# 21. Управляемая автономия

Человек смещается от ручного написания строк к:

- формулированию целей;
- утверждению требований;
- принятию архитектурных решений;
- проверке контрактов;
- разрешению конфликтов;
- утверждению критических изменений;
- контролю качества.

Агент получает свободу внутри утверждённой ветви графа.

```text
Автономия внутри контрактов, графа, тестов и ограничений.
```
