# 20. Наблюдаемое состояние решений ИИ

GRACE требует материализовать ключевые решения модели:

- архитектурный граф;
- контракты;
- семантический каркас;
- мысленные сценарии;
- структурированные логи;
- отчёты о нарушениях.

Это не означает хранить весь внутренний монолог модели. Важны проверяемые артефакты:

```text
решение + основание + связи + критерий проверки + наблюдаемый результат
```

Выводы модели после практического выполнения задачи надёжнее её общей самооценки.

Полезнее:

```text
«По методологии невозможно определить переход между резервированием и сохранением».
```

чем:

```text
«Методология хорошо структурирована».
```
