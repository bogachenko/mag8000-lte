# 2. Какую проблему решает GRACE

При большой задаче LLM должна одновременно удерживать бизнес-цель, архитектуру, границы модулей, состояния, зависимости, уже написанный код, будущую реализацию, ограничения, тестовые критерии и побочные эффекты.

Если всё это существует только в линейном тексте или скрытом состоянии модели, возникают:

- архитектурный дрейф;
- пропуск требований;
- случайное расширение ответственности функций;
- противоречия между удалёнными частями кода;
- фиксация неверного первоначального предположения;
- небезопасный рефакторинг;
- прохождение узких тестов при неработающем реальном сценарии;
- потеря контекста агентом, который получает проект частями.

GRACE выносит замысел в явные, структурированные и связанные артефакты.
