# 14. Агентные тесты

Агентный тест — сценарий высокого уровня, который агент выполняет через Tools.

```markdown
# Проверка повторного проведения заказа

1. Создать заказ с одним товаром.
2. Провести заказ.
3. Сохранить состояние движений.
4. Повторно провести тот же заказ.
5. Получить новое состояние движений.
6. Проверить, что количество движений не увеличилось.
7. Получить trace второго проведения.
8. Убедиться, что было событие IDEMPOTENT_REPLAY_DETECTED.
9. При нарушении извлечь минимальный набор данных и сформировать XML-отчёт.
```

Агентный сценарий не отменяет assertions. Он координирует действия, собирает контекст и запускает детерминированные проверки.
