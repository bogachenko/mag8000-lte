# 19. Сквозная прослеживаемость

Каждый значимый элемент должен иметь стабильный ID и ссылки.

```text
REQ-ORDER-001
→ BP-ORDER-CREATION
→ MOD-ORDER
→ CONTRACT-MOD-ORDER
→ AUTOMATON-SPEC-* (ноль или несколько; по одному на каждый контур с `REQUIRED`)
→ CONTRACT-VALIDATE-ORDER
→ BLOCK-ORDER-VALIDATION
→ TEST-ORDER-VALIDATION
→ TRACE-8F21A7
→ EVT-ORDER-VALIDATION-FAILED
```

По этой цепочке можно пройти:

- от бизнес-требования к коду;
- от функции к причине её существования;
- от теста к контракту;
- от ошибки в логе к блоку кода;
- от патча к затронутым требованиям.
