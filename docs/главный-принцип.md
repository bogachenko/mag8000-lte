# 1. Главный принцип

В GRACE нельзя начинать с кода.

```text
Замысел
→ RequirementsAnalysis
→ семантический граф требований и бизнес-процессов
→ Technology.xml
→ DevelopmentPlan.xml
→ контракты модулей
→ автоматные спецификации (если требуются)
→ контракты классов и функций
→ мысленные сценарии и критерии проверки
→ код
→ автоматические тесты
→ семантические логи и трассы
→ верификация
```

Иерархия источников истины:

```text
Требования
выше архитектурного графа
выше контрактов модулей
выше автоматных спецификаций (если применяются)
выше контрактов функций
выше реализации
```

Нижний уровень не должен молча противоречить верхнему.
