# 9. Код как живой документ

Код, контракты, граф, тесты и логи должны оставаться синхронизированными.

Изменение функции требует проверки:

- изменился ли контракт функции;
- изменился ли контракт модуля;
- изменился ли бизнес-процесс;
- изменились ли критерии приёмки;
- изменились ли события логирования;
- изменились ли связи графа.

Нельзя считать комментарий достоверным, если система не контролирует его соответствие реализации.
