# 6. Контракт как семантический щит

Контракт отделяет намерение от текущей реализации. Код может содержать дефект, временный обходной путь, устаревшее поведение, случайный побочный эффект или неполную реализацию.

При изменении агент сравнивает патч с:

```text
контрактом функции
→ контрактом модуля
→ архитектурным графом
→ требованиями
```

Если патч противоречит контракту, патч отклоняется либо сначала осознанно изменяется вышестоящий замысел и зависимая ветвь графа.

Контракт является одновременно:

```text
спецификацией генерации
+ защитой от архитектурного дрейфа
+ критерием проверки патчей
+ локальным узлом графа знаний
```
