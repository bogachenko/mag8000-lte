# GRACE — полное описание методологии

## Graph-RAG Anchored Code Engineering

GRACE — методология создания, изменения и сопровождения программных систем с помощью LLM и автономных агентов. Её задача — превратить вероятностную генерацию кода в управляемый инженерный процесс, где код создаётся не напрямую из неформального запроса, а как производный артефакт утверждённого семантического графа, архитектуры и контрактов.

Методология рассчитана на новые проекты, большие кодовые базы, RAG-агентов, автономные и swarm-агенты, legacy-системы, ERP, ETL и длинные контексты.
